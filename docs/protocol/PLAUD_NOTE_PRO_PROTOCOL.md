## GATT

| UUID | Use |
|------|-----|
| `00001910-0000-1000-8000-00805f9b34fb` | Plaud service |
| `00002bb0-…` | Notify (device → app) |
| `00002bb1-…` | Write (app → device) |
| `0000180f` / `00002a19` | Standard battery |

Manufacturer data company id `0x005D`: model in bytes 1–2 (`0x0371` = **881** Note Pro; **883** is the same family), serial bytes 9–16, protocol version bytes 18–19.

**OTA:** project codes **881 and 883** disable OTA push in the official app. Velum never sends OTA opcode **143**.

## Framing

All integers little-endian.

- App → device: `[0x01][cmd u16][params]` (trailing zeros trimmed).
- Device → app, byte 0 = type: `1` command response, `2` recording data, `4` speed test, `5` log.

## Protocol 20 unlock (Note Pro; APK + community)

Requires user-held (one-time import, never generated by Velum): serial signature (256 bytes from `/device/sn-sign`), optional RSA-2048 user E2EE key pair, bind token (`user_id` padded with `0`).

1. **Every new connection** with prot ≥ 20: send signature as `0xFE10` chunks `[opcode][total][index][≤100 bytes]` (no `0x01` prefix). Empty signature → handshake fail.
2. If device replies `0xFE11`, send **user** public key PEM via `0xFE12` chunks. With E2EE off, device may skip FE11 (verify on hardware).
3. Device returns session secret via `0xFE12`; RSA-decrypt → `key[32]|nonce[12]|aad[12]|test` (test opens to `PLAUD.AI`).
4. Subsequent packets (notify **and writes**): ChaCha20-Poly1305 with **fixed** key, nonce, and aad for the whole session; plaintext = `seq u32 LE ‖ packet`. App send counter starts at 2 after unlock; seq ≤ last seen is dropped.

## Handshake (cmd 1)

`01 01 00 | 02 00 | P | token`. Response includes status, protocol version, timezone, channels, Wi-Fi flag, Ogg flag.

|-----|------|
| 26 | List sessions (`session_id` = Unix start, size, attrs) |

## Features and Wi-Fi (APK 3.30.0)

| cmd | Role |
|-----|------|
| 138 | FeatureRequest — after skipping 3 payload bytes, **bit 0x08 = AES-GCM Wi-Fi** (else ChaCha20-Poly1305 on the pipe) |
| 120–125 | Sync-in-idle Wi-Fi: get/set SSID+password, list, test, result, delete |
| 116 → 117 | Wi-Fi disconnect |
| SoftAP + WS | Device SoftAP; phone listens WebSocket **`:8081`**; frames use the BLE session key/nonce/aad (+ own seq). BLE must stay up. |

## Never-send opcodes

5 (depair), 104 (clearAllFile), 128 (resetFindmy), 0xFE20, 143 (OTA).

APK unused / uninterpreted (do not send): 5, 13, 38, 50, 51, 109, 141, 142, 145, 151.

## On-device file

Magic `PLAUD.AI`, header 512 bytes, version 1 = RSA-wrapped content key, body = ChaCha20 (no Poly1305). Decrypt → Ogg Opus 16 kHz mono ~32 kbps on Note Pro.

## Gaps

Protocol 30 ECDH, long download resume, exact CRC match — still to harden on owner hardware. Wi-Fi SoftAP + WebSocket `:8081` (Plaud parity) with token preamble and BLE fallback is implemented against the JVM fake; confirm SoftAP on owner hardware. See `WIFI_FAST_PATH.md`.
